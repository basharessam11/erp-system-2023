# نظام إدارة وتقييم الموظفين

📌 نظام ويب متكامل لإدارة الموظفين والحسابات والمشاريع داخل المؤسسات والشركات.  
يوفر النظام لوحة تحكم سهلة الاستخدام، وقوائم متعددة تشمل شئون الموظفين، الحسابات، المشاريع، والتقارير.

---

## ✨ المميزات الرئيسية

- إدارة العملاء والمجموعات.
- إدارة الحسابات (قيود اليومية، المصاريف، سندات القبض، الحسابات، مراكز التكلفة، الأصول).
- شئون الموظفين (ملفات الموظفين، الإدارات، الإجازات، الرواتب، السلفيات، تقييم الموظفين).
- إدارة المشاريع والمهام.
- تقارير مالية وإدارية (ميزان المراجعة، دفتر الأستاذ، تقارير القيود اليومية، تقارير مراكز التكلفة).
- إدارة المستخدمين والصلاحيات.
- إعدادات عامة (عملات، ضرائب، طرق الدفع).
